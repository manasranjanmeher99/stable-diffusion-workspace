# 🚀 Generative AI with Stable Diffusion

A collection of hands-on **Generative AI** projects built using **Hugging Face Diffusers**, **Stable Diffusion**, **Stable Diffusion XL (SDXL)**, and **Stable Audio Open**. This repository demonstrates how to generate high-quality AI images and audio from text prompts while exploring different Stability AI models and Hugging Face pipelines.

---

## 📌 Overview

This repository contains Jupyter notebooks showcasing different generative AI workflows, including:

- 🖼️ Text-to-Image Generation with Stable Diffusion 2
- 🎨 High-Resolution Image Generation using Stable Diffusion XL
- 🔊 Text-to-Audio Generation using Stable Audio Open
- 🤗 Hugging Face Diffusers Pipeline Examples

The goal of this repository is to learn, experiment, and demonstrate the capabilities of modern generative AI models.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/manasranjanmeher99/stable-diffusion-workspace.git

cd stable-diffusion-workspace
```

## Create a virtual environment (Optional)

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook inside the **notebooks/** folder and run the cells.
